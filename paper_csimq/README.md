# CSIMQ submission version

Manuscript formatted for *Complex Systems Informatics and Modeling Quarterly*
(CSIMQ) with the official LaTeX template (`csimq.cls`, `IEEEtran.bst`,
`csimq-header.pdf`).

Compile with **XeLaTeX** (the template uses `fontspec`):

```bash
xelatex main && bibtex main && xelatex main && xelatex main
```

* Times New Roman is used if installed; otherwise TeX Gyre Termes (metrically
  identical) is substituted automatically.
* One fix in `csimq.cls`, line 1044: the header `\includegraphics` option list
  lacked a comma and failed to parse under XeLaTeX (header image missing); a
  comma, `clip` and an adjusted top trim were added.
* Tables in `tables/` and figures in `figures/` are generated by
  `scripts/analyze.py`; refresh them with
  `cp ../paper/tables/*.tex tables/ && cp ../paper/figures/* figures/`.
* The journal fills
  issue number, pages, DOI and dates.
