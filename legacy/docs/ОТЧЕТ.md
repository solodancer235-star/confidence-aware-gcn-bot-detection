## 1. ВВЕДЕНИЕ

### 1.1 Цель проекта

Разработка прототипа системы для автоматического обнаружения бот-сетей в социальной сети Twitter с использованием современных методов анализа графов, семантического анализа текста и графовых нейронных сетей.

### 1.2 Актуальность

Бот-сети представляют серьезную угрозу для социальных сетей:
- Распространение дезинформации
- Манипулирование общественным мнением
- Нарушение целостности платформы
- Финансовые мошенничества (крипто-скамы)

Традиционные методы обнаружения ботов, основанные только на профильных характеристиках, недостаточно эффективны против современных координированных бот-сетей.

### 1.3 Задачи проекта

1. Генерация синтетических данных для тестирования системы
2. Реализация семантического анализа текстовых данных
3. Разработка алгоритмов обнаружения сообществ
4. Создание модели классификации на основе графовых нейронных сетей
5. Визуализация результатов анализа

## 3. РЕАЛИЗОВАННЫЕ ЭТАПЫ

### 3.1 ЭТАП 1: Генерация синтетических данных

#### 3.1.1 Описание

Создан модуль `generate_synthetic_twitter_graph()` для генерации направленного графа, имитирующего структуру социальной сети Twitter.

#### 3.1.2 Параметры генерации

- **Общее количество узлов:** 500
- **Узлы-люди:** 400
- **Узлы-боты:** 100
- **Кластеры ботов:** 2 плотных кластера

#### 3.1.3 Методы генерации

**Для людей:**
- Использована модель предпочтительного присоединения (Barabási-Albert)
- Power-law распределение степеней узлов
- Органические двунаправленные связи
- Случайные дополнительные связи

**Для ботов:**
- Полносвязные кластеры (все боты в кластере связаны друг с другом)
- Межкластерные связи между бот-кластерами
- Связи с людьми для маскировки (2-5 случайных подписок на человека)

#### 3.1.4 Текстовые атрибуты

**Люди:**
- 15 различных тем для твитов
- Разнообразный контент (погода, фильмы, работа, хобби и т.д.)
- Комбинация нескольких тем для каждого узла

**Боты:**
- 10 шаблонов на тему крипто-скама
- Семантически похожие тексты
- Небольшие вариации для имитации разнообразия

#### 3.1.5 Результаты генерации

```
✓ Граф создан: 500 узлов, ~X ребер
  - Людей: 400, Ботов: 100
  - Средняя степень узла: ~Y
```

### 3.2 ЭТАП 2: Семантический слой (SBERT)

#### 3.2.1 Описание

Реализован модуль `add_semantic_edges()` для создания семантических связей между узлами на основе схожести их текстового контента.

#### 3.2.2 Используемая модель

- **Модель:** `all-MiniLM-L6-v2`
- **Размерность эмбеддингов:** 384
- **Преимущества:**
  - Быстрая инференция
  - Хорошее качество для коротких текстов
  - Оптимизирована для семантического поиска

#### 3.2.3 Алгоритм

1. Извлечение всех твитов из узлов графа
2. Вычисление эмбеддингов через Sentence-Transformer
3. Вычисление матрицы косинусного сходства
4. Создание семантических ребер при сходстве ≥ 0.85
5. Сохранение эмбеддингов в атрибутах узлов для дальнейшего использования

#### 3.2.4 Параметры

- **Порог сходства:** 0.85 (настраиваемый)
- **Тип ребер:** `edge_type='semantic'`
- **Атрибут:** `similarity` - значение косинусного сходства

#### 3.2.5 Результаты

```
✓ Добавлено N семантических ребер
  Порог сходства: 0.85
```

**Наблюдения:**
- Боты с похожими текстами получают дополнительные семантические связи
- Это усиливает структуру бот-кластеров
- Помогает модели лучше различать ботов и людей

### 3.3 ЭТАП 3: Обнаружение сообществ

#### 3.3.1 Алгоритм Leiden

**Реализация:** `detect_communities_leiden()`

**Принцип работы:**
- Алгоритм оптимизации модулярности
- Улучшенная версия алгоритма Louvain
- Гарантирует локально оптимальное разбиение

**Процесс:**
1. Конвертация NetworkX графа в формат igraph
2. Применение алгоритма Leiden
3. Получение разбиения на сообщества
4. Вычисление модулярности

**Результаты:**
```
✓ Обнаружено M сообществ
  Модулярность: X.XXXX
```

#### 3.3.2 Spectral Clustering

**Реализация:** `detect_anomalies_spectral()`

**Принцип работы:**
- Использование спектральных свойств матрицы Лапласа графа
- Выделение структурных аномалий
- Кластеризация на основе собственных векторов

**Алгоритм:**
1. Построение матрицы смежности
2. Вычисление нормализованной матрицы Лапласа:
   ```
   L = D^(-1/2) * (D - A) * D^(-1/2)
   ```
3. Вычисление собственных значений и векторов
4. Применение K-means к собственным векторам
5. Получение меток кластеров

**Параметры:**
- Количество кластеров: 10 (настраиваемо)
- Метрика сходства: косинусное сходство

**Результаты:**
```
✓ Spectral Clustering завершен
  Найдено кластеров: K
```

#### 3.3.3 Применение результатов

Информация о сообществах сохраняется в атрибутах узлов:
- `leiden_community` - ID сообщества по Leiden
- `spectral_cluster` - ID кластера по Spectral Clustering

### 3.4 ЭТАП 4: GNN классификация

#### 3.4.1 Архитектура модели

**Класс:** `BotDetectionGCN`

**Структура:**
```
Входной слой (384) → GCN → ReLU → Dropout
                    ↓
            Скрытый слой (64) → GCN → ReLU → Dropout
                    ↓
            Скрытый слой (64) → GCN → ReLU → Dropout
                    ↓
            Выходной слой (2) → Логиты
```

**Параметры:**
- **Входная размерность:** 384 (размерность эмбеддингов SBERT)
- **Скрытая размерность:** 64
- **Выходная размерность:** 2 (бот/человек)
- **Количество слоев:** 3
- **Dropout:** 0.5

#### 3.4.2 Graph Convolutional Network (GCN)

**Принцип работы:**
GCN агрегирует информацию от соседних узлов:

```
h^(l+1) = σ(D^(-1/2) A D^(-1/2) h^(l) W^(l))
```

где:
- `A` - матрица смежности
- `D` - диагональная матрица степеней
- `h^(l)` - признаки узлов на слое l
- `W^(l)` - обучаемые веса слоя l
- `σ` - функция активации (ReLU)

#### 3.4.3 Подготовка данных

**Функция:** `prepare_pytorch_geometric_data()`

**Процесс:**
1. Извлечение эмбеддингов из атрибутов узлов
2. Создание тензора признаков `x` [num_nodes, 384]
3. Создание тензора меток `y` [num_nodes]
4. Создание `edge_index` [2, num_edges]
5. Объединение в объект `Data` PyTorch Geometric

#### 3.4.4 Обучение модели

**Функция:** `train_gnn_model()`

**Параметры обучения:**
- **Оптимизатор:** Adam
- **Скорость обучения:** 0.01
- **Weight decay:** 5e-4 (L2 регуляризация)
- **Функция потерь:** CrossEntropyLoss
- **Количество эпох:** 100
- **Разделение данных:** 80% train / 20% test

**Процесс:**
1. Случайное разделение узлов на train/test
2. Для каждой эпохи:
   - Прямой проход через модель
   - Вычисление потерь на обучающей выборке
   - Обратное распространение ошибки
   - Обновление весов
3. Периодическая оценка на тестовой выборке
4. Финальные предсказания для всех узлов

**Вывод во время обучения:**
```
Эпоха 20/100 | Loss: 0.XXXX | Train Acc: 0.XXXX | Test Acc: 0.XXXX
Эпоха 40/100 | Loss: 0.XXXX | Train Acc: 0.XXXX | Test Acc: 0.XXXX
...
```

**Результаты:**
```
✓ Обучение завершено
  Финальная точность: X.XXXX
```

### 4.2 Обработка данных

**Форматы данных:**
- **NetworkX DiGraph:** Основная структура графа
- **PyTorch Geometric Data:** Для GNN модели
- **NumPy arrays:** Для вычислений
- **Torch tensors:** Для обучения модели

**Преобразования:**
1. NetworkX → igraph (для Leiden)
2. NetworkX → NumPy (для Spectral Clustering)
3. NetworkX → PyTorch Geometric (для GNN)

### 4.3 Оптимизация производительности

**Примененные техники:**
- Batch processing для эмбеддингов
- Векторизованные операции NumPy
- Использование GPU (если доступно) для PyTorch
- Кэширование промежуточных результатов

**Временная сложность:**
- Генерация графа: O(n²) для ботов, O(n log n) для людей
- SBERT эмбеддинги: O(n) где n - количество узлов
- Матрица сходства: O(n²)
- Leiden: O(n log n)
- Spectral Clustering: O(n³) для вычисления собственных значений
- GNN обучение: O(E × L) где E - количество ребер, L - количество слоев

### 4.4 Обработка ошибок

**Реализованные проверки:**
- Проверка наличия ребер перед применением алгоритмов
- Обработка деления на ноль в матрицах
- Проверка наличия эмбеддингов в атрибутах узлов
- Валидация размерностей тензоров

- Выявляет структурные аномалии

- **Точность:** > 0.85 (зависит от параметров)
