# КРАТКИЙ ОТЧЕТ ПО ПРОЕКТУ

## Система обнаружения бот-сетей в Twitter

---

## ЦЕЛЬ ПРОЕКТА

Разработка прототипа системы для автоматического обнаружения бот-сетей в Twitter с использованием графовых нейронных сетей, семантического анализа и алгоритмов обнаружения сообществ.

---

## РЕАЛИЗОВАННЫЕ ЭТАПЫ

### ✅ ЭТАП 1: Генерация синтетических данных
- Создан направленный граф на 500 узлов
- 400 узлов-людей с органическими связями (Power-law)
- 100 узлов-ботов в 2 плотных кластерах
- Текстовые атрибуты: разнообразные твиты для людей, семантически похожие (крипто-скам) для ботов

### ✅ ЭТАП 2: Семантический слой (SBERT)
- Использована модель `all-MiniLM-L6-v2`
- Вычисление эмбеддингов всех твитов (384 измерения)
- Создание семантических ребер при косинусном сходстве ≥ 0.85
- Сохранение эмбеддингов для использования в GNN

### ✅ ЭТАП 3: Обнаружение сообществ
- **Leiden алгоритм:** Первичная сегментация графа, оптимизация модулярности
- **Spectral Clustering:** Поиск структурных аномалий через матрицу Лапласа
- Результаты сохранены в атрибутах узлов

### ✅ ЭТАП 4: GNN классификация
- Архитектура: Graph Convolutional Network (GCN)
- 3 слоя: входной (384→64), скрытый (64→64), выходной (64→2)
- Обучение: 100 эпох, Adam оптимизатор, train/test split 80/20
- Использование эмбеддингов SBERT как признаки узлов

### ✅ ЭТАП 5: Визуализация
- Граф с цветовой кодировкой предсказаний
- Легенда: правильно/неправильно предсказанные боты и люди
- Сохранение в `bot_detection_graph.png` (300 DPI)
